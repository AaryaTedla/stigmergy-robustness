Current status: Phase 2A is complete. Candidate J passed the predeclared clean, stochastic pheromone-benefit gate on all three training seeds. The project can now plan Phase 2B, but attacks, datasets, detectors and robustness claims have not yet been created.

Project: Robust Stigmergic Coordination under Minority Pheromone Injection Attacks
Verified 1 November 2026 · Development-only simulator evidence

1. The project in one page

Agents work together in a simulated grid world. They search for food, pick it up, and deliver it back to a nest. They have only a small local view, but can leave and observe food and home pheromone fields. The main research question is whether a local defense can protect useful learned pheromone coordination from a minority of agents depositing misleading food pheromone.

Before attacking pheromone, we needed evidence that the learned policy actually benefits from it. That was the job of Phase 2A.

Do not overclaim: Candidate J proves a clean development result, not attack robustness. It does not prove that every deterministic rollout coordinates well, that a detector works, or that a defense improves attacked performance.

2. What the agent can and cannot see

Each policy receives a 58-value local observation: a 3×3 patch with six values per cell, then four values describing its own state. The patch includes food, nest, food pheromone, home pheromone, other-agent occupancy and boundaries. The agent can also know whether it is carrying food, has picked up or delivered food, or was blocked.

The policy does not receive global coordinates, the global food map, agent identity, attacker identity, direct messages, privileged labels or a global-state critic. All policies use one parameter-shared PPO model with a 32×32 network and a shared delivery reward.

3. The fair Phase 2A comparison

For every seed, Phase 2A trains two separate models. This is essential: masking pheromone after training would not be a fair no-pheromone baseline.

ModelInput during both training and evaluationPurpose
Full PPOAll 58 local values, including food and home pheromone.The policy whose pheromone use we want to test.
No-pheromone PPOThe same 58-value shape, with exactly the 18 local food/home pheromone entries set to zero.Tests whether pheromone adds value beyond food, nest, walls, nearby agents and own state.
Random actionNo learned policy; legal actions sampled from a separate seeded RNG.Checks that learned policies exceed chance behavior.

The phase used three PPO training seeds—7, 17 and 27—and diagnostic map seeds 100–103. The predeclared gate was strict: full PPO must have higher stochastic mean delivered food than both no-pheromone PPO and random action on every one of the three seeds.

5. What Candidate J does

Candidate J preserves Candidate G's stable scout-and-follow structure and increases only the food capacity. This removes the delivery ceiling that hid a speed advantage in Candidate G.

Grid12×12Small enough for CPU PPO, but with a meaningful search route.

Food layoutTwo adjacent cells far from the nest; location varies by reset seed.One scout can discover a distant source; fixed-location memorization is discouraged.

Horizon1,100 stepsRetains the stable long version rather than H/I's failed short deadline.
Field settingsDeposit 1.0, cap 10.0, evaporation 0.02Retains the previously tested slow-fading field.
Training300,000 requested agent transitions per policySame PPO settings, modes and seeds as Candidate G.

Candidate J assumptions

  1. A full policy that can use local pheromone should turn the scout's discovered route into better team delivery than a separately trained no-pheromone policy.
  2. Candidate G's seed-7 tie was partly caused by both policies reaching the old 60-unit maximum, not proof that pheromone had no value.
  3. Increasing capacity while keeping the long horizon tests that explanation more cleanly than changing rewards, network size or several environment settings at once.
  4. Seed-varying food locations prevent a policy from relying only on one memorized route.

A frozen-policy diagnostic supported the first assumption: masking only local pheromone changed Candidate G full-policy action distributions by total variation 0.272, 0.187 and 0.230 for seeds 7, 17 and 27, respectively. This shows input sensitivity, not causal proof by itself.

8. How to start Phase 2B

Phase 2B should test whether a bounded minority false-food pheromone attack harms the useful Candidate J behavior, then whether a local defense helps. Do not jump directly to a large dataset: first freeze a small, auditable attack-calibration protocol.

Recommended first deliverable: write a Phase 2B decision record before changing code or producing trajectories. It should name the Candidate J checkpoints, development maps, attacker fraction, injection budget, attack modes, clean/injection-disabled/attacked controls, metrics, and grouped train/validation/test split rules.

Phase 2B sequence

  1. Freeze the clean reference. Use Candidate J’s completed full PPO checkpoints unchanged. Do not retrain them after seeing attack results.
  2. Declare attack calibration. Start with the existing bounded, nonnegative false-food injector. Deposits must occur only at selected attackers’ actual occupied cells and use the same field cap and evaporation as honest deposits.
  3. Run three controls on the same maps. Compare clean, injection-disabled and attacked conditions. Injection-disabled separates pheromone effects from simply losing productive workers.
  4. Measure attack effect first. Report honest/team food delivered, completion, episode length, requested/authorized/applied injected mass, compromised-agent fraction and stochastic seed variation.
  5. Create grouped splits before windows. Keep all variants from one complete map/episode group in the same split before generating temporal detector windows. Hold out maps and at least one attack configuration for final evaluation.
  6. Evaluate defenses fairly. Compare undefended pheromone coordination, separately trained no-pheromone PPO, the local timeout baseline and a documented cautionary-pheromone adaptation. Defense inputs may use only local pheromone change, revisitation and the agent's own progress.
  7. Keep final claims separate. Development calibration selects the protocol; held-out maps and attack settings support the final robustness claim.
Non-negotiable boundaries: no pheromone erasure, negative deposits, global field writes, reward tampering, policy modification, attacker identities, global food locations, direct communication or privileged labels as defense inputs.

10. Final handoff statement

We now have a clean, reproducible stochastic result showing that pheromone information helps the learned team in Candidate J. The correct next move is not to change Candidate J again. Freeze it, define Phase 2B’s attack-calibration contract, then test whether bounded false pheromone can damage this useful coordination and whether strictly local defenses can recover it.
