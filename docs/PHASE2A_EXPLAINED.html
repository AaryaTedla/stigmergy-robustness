Phase 2A Explained

Local values, seeds, fair policy comparisons, and why Candidate J is the best current clean-task candidate

Short version. Phase 2A checks whether agents learn a useful benefit from nearby pheromone information before the project spends effort on attacks, detector data, or robustness evaluation. Candidate J is the best current candidate because it is the first tested setup where the full-input PPO policy beat both a separately trained no-pheromone PPO policy and random actions for all three experiment seeds.

1. The project in simple words

Agents move in a grid, collect food, and carry it back to a nest. They can leave two kinds of pheromone-like values in the grid:

  • Food pheromone: deposited by an agent that is carrying food, so it can potentially indicate a route connected to food.
  • Home pheromone: deposited by an empty agent travelling away from the nest, so it can potentially indicate the return direction or an explored route.

The project uses one shared PPO neural-network policy for all agents. It must learn what to do from what each individual agent can see. The central clean-task question is therefore: does access to local pheromone values actually help that learned policy deliver more food?

2. What “local values” means

Here, local does not mean a programming variable. It means information available close to one agent’s current grid position. An agent cannot see the whole world.

At every time step, one agent receives a 3 by 3 window centred on itself:

Part of the observationValuesMeaning
3 by 3 nearby cells9 cells × 6 values = 54The agent sees only itself, its immediate neighbours, and diagonal neighbours.
Own state4 valuesWhether it is carrying food, picked up food, delivered food, or was blocked on this step.
Total58 valuesThis 58-number vector is the policy input for one agent.

For each of the nine visible cells, the six local values are:

  1. Food present or not
  2. Nest present or not
  3. Normalised food-pheromone amount
  4. Normalised home-pheromone amount
  5. How occupied that cell is by agents
  6. Whether the cell is outside the grid boundary
Important limitation: the policy is not given absolute coordinates, the complete food map, a global pheromone map, agent identities, attacker identities, attack labels, or direct messages from other agents. It only receives a local 3 by 3 view and its own immediate progress state.

Why this matters

If an agent turns toward stronger food pheromone after seeing it in a nearby cell, that is a local decision. It does not need—and is not allowed—to know where all food is globally. This is the intended decentralised coordination setting.

3. What a seed is, using this experiment

A seed is a fixed starting number for all controlled random choices. You can think of it as choosing a particular repeatable “randomness recipe.” It makes an experiment reproducible.

With seed 7With seed 17With seed 27
The experiment uses one reproducible set of random choices.It repeats the same method using a different reproducible set of random choices.It repeats it a third time using another reproducible set.

In this project, such controlled randomness can affect the seed-specific food layout, PPO neural-network initialisation, training/action sampling, and pickup contention order. The rules, model architecture, training budget, grid configuration, and evaluation method stay the same.

For each seed, the comparison is paired:

Seed 7: Full PPO versus No-Pheromone PPO versus Random
Seed 17: Full PPO versus No-Pheromone PPO versus Random
Seed 27: Full PPO versus No-Pheromone PPO versus Random

So it is reasonable to describe these as experiment repetitions 1, 2, and 3. The actual numbers 7, 17, and 27 have no special scientific meaning; they are just chosen reproducible identifiers. Repeating across seeds helps show that a result is not simply a lucky neural-network start or an unusually easy map.

Why one seed is not enough: if Full PPO wins only on seed 7, it could be luck. A strong Phase 2A result requires it to win for seeds 7, 17, and 27, under the predeclared rule.

4. Why Phase 2A was needed

Before Phase 2A, the simulator and PPO training pipeline worked, but the available evidence did not show a reliable pheromone benefit. Clean and attacked development delivery were equal in the earlier review checkpoint; deterministic actions delivered zero; and a frozen-policy diagnostic that hid pheromone inputs slightly improved sampled delivery. Therefore, it would have been scientifically weak to immediately generate a large attack or detector dataset.

Phase 2A is a development-only gate. It asks one narrow question before later stages begin:

Can a clean learned policy show a reproducible delivery advantage when it receives local pheromone values?

It is not an attack experiment. It does not fit a detector, create final train/test splits, or prove robustness.

5. The fair Phase 2A comparison

Each environment candidate and seed has two independently trained PPO policies:

ModePolicy inputPurpose
FullAll 58 local values, including food and home pheromone values.Tests the intended local-pheromone policy.
No-pheromoneStill has 58 positions, but the 18 pheromone entries are zero: 9 cells × 2 pheromone channels.Tests how well the policy can do without pheromone information.
RandomNo learned policy; actions are random.Checks that both learned policies are meaningfully better than untrained movement.

The no-pheromone baseline still sees food, the nest, occupancy, boundaries, and its own carrying/progress values. The simulator itself is not changed. Only a copied observation batch sent into the no-pheromone policy is masked.

This distinction is essential:

  • Not fair: train a full-input policy, then hide pheromones only after training. The policy is suddenly tested on unfamiliar input.
  • Fair: train a separate policy from the start with pheromone entries zero, then evaluate it in the same way.

What remains the same in each matched pair

Environment candidate, PPO architecture (shared 32-by-32 actor/local critic), reward, map sets, seed, training budget, diagnostic maps, and evaluation procedure. The intended difference is access to the 18 local pheromone values.

6. How a candidate passes

The predeclared condition is strict. On the stochastic mean delivered food metric, Full PPO must strictly beat:

  1. its same-seed separately trained no-pheromone PPO, and
  2. the random-action reference,

for every one of seeds 7, 17, and 27.

Stochastic evaluation means the policy samples actions from its learned action probabilities. Deterministic evaluation instead always selects the most likely action. Both are reported separately. The Phase 2A gate is based on stochastic delivery, and Candidate J’s deterministic results are explicitly recorded as mixed.

8. Candidate J: exact design

Candidate J deliberately keeps the successful stable parts of Candidate G and changes only one factor. This is why it is a well-controlled follow-up rather than a completely new experiment.

FeatureCandidate J settingWhy it matters
Grid12 by 12Retains the scout-and-follow environment.
Agents4Same as Candidate G.
Food layoutTwo adjacent, distant food cells; location varies by map seedA scout can find food and leave a trail that may help other agents follow.
Horizon1,100 stepsRetains the long horizon that trained stably.
Pheromone evaporation2% per stepRetains slower fading so local trails remain visible long enough to be potentially useful.
Food per patch50 units instead of Candidate G’s 30The only environmental change; raises total capacity from 60 to 100 units.
TrainingThree seeds × two PPO modes = six fresh PPO jobs, plus three random referencesPreserves the paired comparison requirement.

Why changing food capacity was the right next test

Candidate G’s full-input policy delivered the maximum 60 food units on all three seeds. On seed 7, no-pheromone PPO also reached 60. Therefore, the final delivery score could not show that Full PPO finished faster; both policies had hit the score ceiling.

Candidate J increased only the food capacity to 100 units total. This created room for a real difference in delivered food to appear. It did not add global information, direct communication, agent identities, reward shaping, attacks, detector features, or a new policy architecture.

Why Candidate J is best: it is the first candidate with a positive Full-minus-No-Pheromone delivery difference on every required seed and a Full-over-Random win on every seed. It therefore satisfies the written Phase 2A advancement condition.

How to interpret those numbers

For seed 7, the full-input model delivered 100 units on average while the separately trained no-pheromone model delivered 68.75. The difference is 100.00 − 68.75 = 31.25 more food units. The same direction occurs for seeds 17 and 27. Because this repeats across all three seeds, the evidence is stronger than a one-run success.

11. Final takeaway

Phase 2A was not simply “train a model and see a high score.” It was a controlled investigation:

  1. Use only decentralised, local observations.
  2. Train a fair no-pheromone baseline from scratch.
  3. Repeat with three reproducible seeds.
  4. Compare against random actions too.
  5. Keep failed and mixed results instead of hiding them.
  6. Change one documented idea at a time.

Candidate J is currently the strongest clean-policy candidate because it is the first one to pass every required paired stochastic comparison. This justifies Phase 2B planning, while keeping all attack, detector, robustness, and held-out-evaluation claims for later work.
