This report distinguishes verified development work from future research claims. It is about a simulated grid world; it does not claim hardware-robot validation.

1. The project in plain language

Our agents work in a two-dimensional grid. They collect food and take it to a nest. They cannot send direct messages. Instead, they leave and sense shared food and home pheromone fields. This indirect coordination through changes in the environment is called stigmergy.

Main question: Can agents learn to cooperate using local pheromone trails, and can a lightweight local defense reduce the harm caused by a small number of agents placing misleading food trails—without making normal clean-task performance much worse?

Scope boundary

  • It is a reproducible simulation study, not a test with physical robots or real ants.
  • All learned-policy claims use one parameter-shared PPO policy; rule-based agents are only debugging/baseline tools.
  • The attacker may only add bounded, nonnegative false-food pheromone at the cell it really occupies. It cannot erase trails, alter rewards, change food locations or edit model weights.
  • A future defense must use only local sensing, local history and an agent’s own progress—not attacker IDs, global maps, or privileged labels.

The core system, in one simulator step

  1. All agents choose an action; legal movement is applied at the same time.
  2. An agent may pick up food or deliver it to the nest.
  3. Honest agents deposit ordinary pheromone; in an attacked run, selected agents may add bounded false food pheromone at their current cell.
  4. The pheromone fields are capped and then fade through evaporation.
  5. Each agent receives its next local observation, reward and episode status.

Important mechanics correction

Empty agents moving outside the nest leave a home trail that weakens after each movement since their last nest visit. A stationary or blocked empty agent outside the nest deposits no home pheromone. This removed an earlier false hotspot that could grow simply because an agent waited at an exhausted food patch.

3. Results: what they mean and what they do not mean

Phase 2A: a clean pheromone-benefit gate was passed

Before testing attacks, the project needed evidence that pheromone helps the learned policy in a clean task. Candidate J uses a 12×12 grid, four agents, two distant adjacent food cells, an 1,100-step horizon and slow 2% evaporation. Six fresh PPO runs (full/no-pheromone × seeds 7, 17, 27) plus three random references were completed.

Meaning: on this declared development task, local pheromone input improved stochastic performance. This is a necessary foundation for attack work, not final proof that every policy/general setting coordinates robustly through pheromone.

Phase 2B: preserve the negative attack result

Each policy/map pair was evaluated as a matched triplet: clean, injection disabled (the same agent is designated but deposits nothing) and attacked. The primary measure is:

injection loss = honest delivery(disabled) − honest delivery(attacked)
A positive value means the injection reduced honest delivery. Zero or negative values do not support reliable disruption.

Correct conclusion: these persistent false-pheromone settings were not shown to reliably harm Candidate J. Do not claim the attack is harmless in every situation; instead, declare a new bounded attack-calibration plan before training/tuning a detector or claiming defense success.

4. What should be done next

  1. Write and approve a new bounded attack-calibration decision—e.g., a decoy or intermittent pattern—while keeping the occupied-cell, nonnegative and budgeted threat boundary.
  2. Run matched clean, disabled and attacked development episodes and advance only if delivery degradation is reliable.
  3. Freeze grouped train/validation/test map and attack splits before temporal windows are made. Related episodes must never be split across train and test.
  4. Fit local-only detector candidates on training groups; choose model/threshold/mitigation once on validation data.
  5. Compare undefended PPO, separately trained no-pheromone PPO, timeout baseline, cautionary-pheromone adaptation and the selected local detector/mitigation.
  6. Run final evaluation on held-out maps and an attack configuration never used for design choices. Report clean cost, attack loss, recovery, false alarms, delay and training-seed variability.

Why this order matters

A detector cannot honestly be called successful if it is trained/tuned on an attack that has not been shown to cause a meaningful task problem. Grouped data splits also prevent leakage: nearly identical pieces of the same episode must not appear in both training and test sets.

5. Papers to read — recommended order

Read the first five before writing the literature review. The last two provide implementation/real-swarm context. Each entry says exactly why it matters for this project.

1. Aswale et al. (2022), Hacking the Colony: On the Disruptive Effect of Misleading Pheromone and How to Defend Against It

Start hereAttack + mitigation

Closest conceptual anchor. It studies misleading food pheromone, minority disruptors and cautionary pheromone. Use it to explain what is already established, and why our project must not claim that false pheromone or cautionary trails are new.

arXiv:2202.01808 · AAMAS 2022.

2. Xu et al. (2022), Stigmergic Independent Reinforcement Learning for Multiagent Collaboration

Core learning context

Explains how digital pheromone can act as indirect communication for learning agents. Compare its independent/federated learning setup with our parameter-shared PPO design; do not describe them as the same method.

DOI: 10.1109/TNNLS.2021.3056418.

3. Schulman et al. (2017), Proximal Policy Optimization Algorithms

Method

The original PPO paper. Read the main objective/algorithm sections to explain why PPO is used and what a policy update means. It supports the RL method; it does not prove multi-agent robustness.

arXiv:1707.06347.

4. Aina & Ha (2026), Deep Reinforcement Learning for Multi-Agent Coordination

Closest learned-stigmergy comparison

Studies virtual pheromones for decentralized coordination in a congested setting. Use it to compare task design, scaling and curriculum learning. Their learning method is not our PPO pipeline.

DOI: 10.1007/s10015-025-01089-z.

5. Standen, Kim & Szabo (2025), Adversarial Machine Learning Attacks and Defences in Multi-Agent Reinforcement Learning

Security framing

A MARL security survey that gives vocabulary for attack surfaces, execution-time attacks and defense trade-offs. Use it to position our environment-mediated false signal as an indirect malicious influence, not a direct edit of policy parameters.

DOI: 10.1145/3708320.

6. More useful papers and a reading plan

6. Li et al. (2025), Attacking Cooperative Multi-Agent Reinforcement Learning by Adversarial Minority Influence

Attack comparison

Shows that a minority adversary can influence cooperative MARL through learned action-based attacks. It is useful for framing, but its attack is much stronger and different from our local, bounded pheromone-deposit attacker. Do not use it as evidence that our attack must work.

arXiv:2302.03322.

7. Hunt et al. (2019), Testing the Limits of Pheromone Stigmergy in High-Density Robot Swarms

Mechanics / limitations

Useful for understanding pheromone saturation, evaporation and congestion. It motivates why field dynamics must be measured rather than assumed beneficial at every agent density.

DOI: 10.1098/rsos.190225.

8. Salman et al. (2020), Phormica: Photochromic Pheromone Release and Detection System for Stigmergic Coordination in Robot Swarms

Optional physical context

Physical swarm-robotics context for artificial pheromone. Read it to explain the inspiration, but clearly state that our current evidence is only simulation-based.

DOI: 10.3389/frobt.2020.591402.

7. Glossary: complex words in simple language

WordSimple meaning here
StigmergyIndirect teamwork: one agent leaves an environmental trace and another later reacts to it.
Pheromone fieldA grid of numbers representing the strength of recent trail deposits. It is not food, a distance, trust, or a probability.
PPOProximal Policy Optimization: a reinforcement-learning method that improves a neural-network action policy from trial-and-error experience.
Parameter-sharedAll agents use the same learned network weights. They can still act differently because they see different local observations.
Local observationThe small patch of information one agent can see near itself, not the whole map.
Stochastic actionAn action sampled from the policy’s probabilities. It can vary even in the same situation.
Deterministic actionAlways selecting the policy’s highest-probability action.
CalibrationA controlled development check to see whether a setting produces the effect needed before building later work on it.
Matched controlA comparison run with the same model, seeds and settings, changing only the condition being tested.
Injection-disabledA control where the same attacker-designated agent exists but deposits no false pheromone, separating injection effects from worker designation.
EvaporationOld pheromone values gradually decrease every step, so trails fade.
Held outKept aside while designing the system, then used only for final testing.
Data leakageAccidentally letting test information—or highly related samples—help training, giving an unrealistically good result.
Temporal windowA short sequence of consecutive time steps used as one detector input example.
CheckpointA saved copy of the learned model at a particular stage of training.
RobustnessHow well the system keeps working when it faces difficult or malicious conditions it was not tuned for.

One-sentence conclusion

The capstone is well beyond the idea stage: it has a tested simulator, trained-policy pipeline, fair clean pheromone evidence, controlled attacks and a carefully separated development dataset. The crucial next step is to find a legal, reliably harmful attack setting before claiming a detector or defense works.
